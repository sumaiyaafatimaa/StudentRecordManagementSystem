# Student Record Management System

## Project Overview
A GUI-Based Student Record Management System developed using C++ and Windows API.

## Features
- Add student records
- View student records
- Update existing records
- Delete student records
- Store records in a text file

## Student Information
The system stores:
- Student Name
- Roll Number
- Father's Name
- Caste
- District
- GPA

## Technologies Used
- C++
- Windows API
- File Handling
- Visual Studio Code
- MinGW Compiler
